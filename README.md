# Dermatology – Data-Centric AI

Data-centric analysis of a dermatological disease classification dataset using the **CRISP-DM methodology**.

This project is developed as part of the **Data-Centric AI** course examination at the University of Bologna.

## Dataset

[Dermatology Dataset – Kaggle](https://www.kaggle.com/datasets/olcaybolat1/dermatology-dataset-classification)

- **366** instances
- **34** features
- **6** dermatological disease classes

## Project Objectives

- Exploratory Data Analysis and Data Profiling
- Data Cleaning and Quality Assessment
- Feature Engineering and Selection
- Dataset Optimization and Class Imbalance Handling
- Machine Learning Classification
- Model Evaluation
